### Capabilities

**Good fit - auto-route when enabled:**
- Bug fixes with clear reproduction steps
- Test coverage, linting, formatting, and dependency updates
- Small isolated features with approved specifications
- Scaffolding and documentation changes

**Needs review - route with a named Squad reviewer:**
- Medium features with approved acceptance criteria
- Refactoring with existing test coverage
- API additions following established patterns
- Well-defined migrations

**Not suitable - route to a named Squad member:**
- Architecture or platform selection
- Ambiguous product decisions
- Identity, privacy, security, payment, or legal-critical changes
- Multi-system integration strategy
- Public claims or content requiring professional review
